# Changelog

## 2.0.0 — 2026-09-04

### Added

- Source-faithful local summaries with Chrome on-device AI support and deterministic fallback.
- Compact Answer Map with Outline, Actions, Sources, Code, search, and source navigation.
- Semantic progressive reading with Focus, Balanced, Full context, and full-answer restoration.
- Private Saved insights library with search, notes, copy, deletion, Markdown export, and JSON backup/restore.
- First-run onboarding, redesigned popup, Chrome MV3 and Firefox MV2 builds.
- Five 1280×800 store screenshots plus small and marquee promotional artwork.

### Changed

- Repositioned the product as **Unfold AI — Summarize & Navigate AI Answers**.
- Waits until generation finishes and leaves short answers untouched.
- Removed the unverified broad `x.com` permission; Grok support is limited to `grok.com`.
- Release packaging now uses an explicit production allowlist.
- Replaced the legacy reader glyph with the folded Unfold “U” across Chrome, Firefox, product UI, and all store artwork; added the high-contrast sunrise-coral icon field.

### Security

- Runtime messages and imported backups are schema- and size-validated.
- No runtime dependencies, remote code, account, analytics, or cloud processing.
- Added a public, rendered privacy-policy document for browser-store disclosure.

## 1.0.0 — 2026-04-17

- Initial public release.
